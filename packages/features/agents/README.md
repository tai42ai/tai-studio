# @tai42/feature-agents

The agents surface for the Studio. Lists the skeleton's registered agents and
runs one with a live streaming timeline that renders each event as it arrives,
and stacks an authoring surface on top for composing and running your own
authored agents. Depends only on `@tai42/studio-sdk`, `@tai42/api-client`, and
TanStack Query.

## Usage

```tsx
import { AgentsPage } from '@tai42/feature-agents';

<AgentsPage />;
```
