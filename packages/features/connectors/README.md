# @tai42/feature-connectors

The connectors surface for the Studio: browse providers, manage connections, and
run the OAuth popup flow that links the skeleton to outside apps. Depends only on
`@tai42/studio-sdk`, `@tai42/api-client`, and TanStack Query.

## Usage

```tsx
import { ConnectorsPage } from '@tai42/feature-connectors';

<ConnectorsPage search={{}} />;
```
