# @tai42/feature-extensions

The tool-extensions surface for the Studio: a read-only catalog of the
skeleton's extensions plus the flow for applying an extension to a tool. Depends
only on `@tai42/studio-sdk`, `@tai42/api-client`, and TanStack Query.

## Usage

```tsx
import { ExtensionsPage } from '@tai42/feature-extensions';

<ExtensionsPage search={{}} />;
```
