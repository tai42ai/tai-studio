# @tai42/feature-hooks

The hooks surface for the Studio: a topic filter over a table of the skeleton's
registered lifecycle hooks, with per-row delete and a register form. Depends
only on `@tai42/studio-sdk`, `@tai42/api-client`, and TanStack Query.

## Usage

```tsx
import { HooksPage } from '@tai42/feature-hooks';

<HooksPage search={{}} />;
```
