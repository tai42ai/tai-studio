# @tai42/feature-manifest

The manifest surface for the Studio: inspect the skeleton's loaded manifest, the
MCP server status and config, and the derived sub-MCP servers. Depends only on
`@tai42/studio-sdk`, `@tai42/api-client`, and TanStack Query.

## Usage

```tsx
import { ManifestPage } from '@tai42/feature-manifest';

<ManifestPage search={{}} />;
```
