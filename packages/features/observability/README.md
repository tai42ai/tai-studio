# @tai42/feature-observability

The observability surface for the Studio: the monitoring dashboard with runs and
traces over the skeleton. Depends only on `@tai42/studio-sdk`, `@tai42/api-client`,
and TanStack Query.

## Usage

```tsx
import { ObservabilityPage } from '@tai42/feature-observability';

<ObservabilityPage search={{}} />;
```
