# @tai42/feature-scheduling

The scheduling surface for the Studio: list, create, and delete schedules that
run backend tools on the skeleton. Depends only on `@tai42/studio-sdk`,
`@tai42/api-client`, and TanStack Query.

## Usage

```tsx
import { SchedulingPage } from '@tai42/feature-scheduling';

<SchedulingPage search={{}} />;
```
