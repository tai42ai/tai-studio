# @tai42/feature-settings

The settings surface for the Studio: a config-mode header above a four-tab
workbench — Settings, Environment, API keys, and Backup — over the skeleton's
configuration. Depends on `@tai42/studio-sdk`, `@tai42/api-client`, TanStack Query,
and `@dnd-kit/core` (the drag-and-drop scope mapper in Access control).

## Usage

```tsx
import { SettingsPage } from '@tai42/feature-settings';

<SettingsPage search={{}} />;
```
