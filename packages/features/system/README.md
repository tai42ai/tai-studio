# @tai42/feature-system

The system surface for the Studio: the skeleton's health and metrics at a
glance. Depends only on `@tai42/studio-sdk`, `@tai42/api-client`, and TanStack
Query.

## Usage

```tsx
import { SystemPage } from '@tai42/feature-system';

<SystemPage search={{}} />;
```
