# @tai42/feature-templates

The templates surface for the Studio: a master list of the skeleton's templates
with an escaped-content detail view, plus upload, delete, render-preview, and
clear-cache actions. Depends only on `@tai42/studio-sdk`, `@tai42/api-client`, and
TanStack Query.

## Usage

```tsx
import { TemplatesPage } from '@tai42/feature-templates';

<TemplatesPage search={{}} />;
```
